# Release notes

Newest first. One line per change. Written by `tools/bump-version.mjs` on each
release, and shown in the app under **More → What's new**.

Each line is tagged `fix:`, `new:` or `better:` so the app can put an icon beside it.

## 1.0.0 — 2026-10-04
- new: Habits: yes/no, count or minutes; daily, chosen days, N a week, N a month or every N days; streaks, reminders and a six-month heatmap
- new: Today: a ring for the day, a 14-day strip to fill in missed days, confetti when every habit is done
- new: Fitness: cardio log with WHO weekly targets and calorie estimates, a strength library by muscle group with a body map, and guided routines with a timer
- new: Diary: mood, energy and feelings, typed or dictated, with voice notes recorded in the app
- new: Reports for a week, month or year: habit completion, active minutes, mood and how habits and mood go together
- new: Settings: profile with BMI, goals, theme and colours, reminders, GitHub sync with history, backup and restore, CSV export
