# Exercise illustrations

The `NNNN-relaxation.svg` (start) and `NNNN-tension.svg` (finish) drawings in
this folder are from **Everkinetic** (https://everkinetic.com,
https://github.com/everkinetic/data) by Greg Priday, licensed under
**CC BY-SA 4.0** (https://creativecommons.org/licenses/by-sa/4.0/).

Changes made: the fixed `width` and `height` attributes were removed from each
file's root element so the drawings scale to their container. These files
remain under CC BY-SA 4.0.

Which drawing goes with which exercise is the `MV_EK` map in `moves.js`.
